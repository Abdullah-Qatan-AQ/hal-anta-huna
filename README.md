# أطياف الممر — ملف 07

إعادة بناء كاملة لرواية رعب تفاعلية عربية مستقلة. النسخة الحالية تحتوي على **9 مشاهد مترابطة عبر 3 فصول**، ثلاث نهايات، نظام توتر وأدلة، حفظ محلي، ألغاز فعلية (قفل أرقام، ترتيب قطع بالسحب، وذاكرة أزواج)، صوت راوية وصوت شخصية، موسيقى خلفية، ومشهد كاميرا حقيقية مع طبقة شخصية شفافة.

## التشغيل

```bash
python3 -m http.server 4173
```

ثم افتح `http://localhost:4173`.

## الأصول

- `assets/narrator-chapter1.wav`: تعليق صوتي عربي للفصل الافتتاحي.
- `assets/noor-dialogue.wav`: حوار نور بصوت هامس.
- `assets/underpass-ambience.wav`: موسيقى/جو خلفي أصلي.
- `assets/generated-corridor.jpg` و`generated-control-room.jpg`: بيئات رعب جديدة.
- `assets/generated-character.png`: شخصية شفافة جديدة للكاميرا.

توليد الفيديو غير متاح في حساب الجلسة الحالي، لذلك لم أضع ملفات فيديو وهمية أو روابط مكسورة. بنية المشاهد جاهزة لإضافة MP4 لاحقًا عبر `videoStage`.

## الخصوصية

الكاميرا اختيارية وتبقى في المتصفح، ولا يتم رفع البث أو الصور. طبقة الشخصية الحالية ثابتة بالنسبة إلى إطار العرض؛ تثبيت حقيقي في العالم عبر AR/WebXR يحتاج تتبعًا بصريًا أو عمقًا من الجهاز، ولا ينبغي وصف طبقة CSS بأنها تتبع ثلاثي الأبعاد مثالي.
