# أطياف الممر — فيلم رعب تفاعلي

رواية رعب تفاعلية عربية مستقلة من كتابة وتطوير **Abdullah Qatan**. النسخة الحالية مبنية كفيلم قصصي من **11 مشهدًا مترابطًا عبر 3 فصول**: رسالة نور، التحقيق داخل المبنى 9، ظهور الساكن، ثم قرار نهائي ينتج **سبع نهايات مختلفة فعلية**.

## الأنظمة

تحتوي اللعبة على مدير صوت يمنع تداخل التسجيلات ويوقف التسجيل السابق قبل تحميل التالي، موسيقى خلفية مستقلة، قراءة للنص الحالي فقط، حفظ محلي، دفتر أدلة، عداد خطر مؤثر في التجربة، وعدادات تنازلية في مراحل القفل ولوحة الأسلاك. الألغاز مبنية على أدلة واضحة داخل القصة: قفل ألوان، لوحة أسلاك، رمز حسابي، واختبار المرآة.

## التشغيل

```bash
python3 -m http.server 4173
```

ثم افتح `http://localhost:4173`.

## الأصول

- `assets/narrator-chapter1.wav` و`narrator-chapter2.wav` و`narrator-chapter3.wav`: تسجيلات السرد.
- `assets/noor-dialogue.wav` و`assets/noor-message.wav`: تسجيلات نور.
- `assets/underpass-ambience.wav`: الموسيقى والجو الخلفي.
- ملفات الصور في `assets/`: بيئات ومراجع بصرية وطبقة العدسة.

## الخصوصية

الكاميرا اختيارية وتبقى داخل المتصفح. لا يتم رفع البث أو الصور إلى خادم خارجي.
