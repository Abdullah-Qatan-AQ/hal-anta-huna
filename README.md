# أطياف الممر

**أطياف الممر** رواية رعب تفاعلية عربية مستقلة تعمل مباشرة في المتصفح. لا تعتمد نقطة الدخول الحالية على أي محرك روايات تفاعلية خارجي أو مكتبة تشغيل لطرف ثالث.

## التجربة

ثلاثة فصول قابلة لإعادة اللعب، اختيارات تغيّر التوتر والأدلة ومسار النهاية، ألغاز سردية، دفتر أدلة، قراءة صوتية عربية عبر Web Speech API، وكاميرا حقيقية اختيارية مع طبقة شخصية فوق البث المحلي. لا يتم رفع الصور أو البث إلى أي خادم.

## التشغيل المحلي

```bash
python3 -m http.server 4173
```

ثم افتح `http://localhost:4173`.

## البنية

- `index.html`: إطار التطبيق والمشاهد والأدوات.
- `style/main.css`: الهوية البصرية المتجاوبة.
- `js/main.js`: القصة والاختيارات والألغاز والحفظ والقراءة الصوتية والكاميرا.
- `assets/`: الأصول المرئية والصوتية المستخدمة داخل التجربة.

## الخصوصية والملكية

الكاميرا اختيارية وتبقى في المتصفح. ملفات المحرك السابق أزيلت من النسخة الحالية. حذف الملفات من آخر نسخة لا يمحو تاريخ Git القديم، ولا يشكل هذا البيان نقلًا قانونيًا لحقوق أي أصل خارجي؛ راجع تراخيص الأصول التي لم تُنشئها بنفسك قبل النشر التجاري.
