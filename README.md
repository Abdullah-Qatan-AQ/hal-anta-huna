# هل أنت هنا؟

**هل أنت هنا؟** لعبة رواية تفاعلية عربية مستقلة للويب، مبنية على منطق تشغيل قصصي مفتوح المصدر معاد تقديمه بواجهة وهوية جديدة.

## التجربة

صُممت الواجهة للعربية أولًا باتجاه RTL، مع مظهر سينمائي داكن، ألوان ليلية ولمسات ذهبية، وقائمة متجاوبة مع الهاتف وسطح المكتب. تدعم اللعبة الحفظ والاسترجاع، سجل الحوار، التشغيل التلقائي، التخطي، التراجع، الوسائط المتعددة، الترجمة، والعمل دون اتصال عند تشغيلها عبر خادم ويب.

## التطوير

يتطلب المشروع Node.js وnpm، وتُستخدم Bun لبناء الحزم النهائية. بعد تثبيت الاعتماديات شغّل:

```bash
npm install
npm run check
npm run lint
```

لبناء ملفات التوزيع النهائية استخدم `bun run build`.

## الاختصارات

يمكن استخدام `M` لتفعيل الوضع السينمائي وإخفاء عناصر القائمة السريعة، و`Escape` لتفعيل نمط التركيز عند اللعب بلوحة المفاتيح.
