# أطياف الممر — فيلم رعب تفاعلي وتطبيق

فيلم رعب تفاعلي عربي مستقل من كتابة وتطوير **Abdullah Qatan**. القصة واضحة ومقسمة إلى ثلاثة فصول، مع تعريف مسبق بالشخصيات والثيمة، تحقيق وأدلة، عدادات وقت وخطر، وأربع نهايات تحقيقية تقود إلى سبع نهايات نهائية.

## الأصول المدمجة

لا تستخدم اللعبة `SpeechSynthesis` أو `AudioContext` أو أي توليد صوت/موسيقى/صور من المتصفح. كل الصوت والصور ملفات محلية داخل `assets`، وتُنسخ إلى حزمة التطبيق عند تشغيل `npm run cap:sync`. التسجيلات لا تتداخل: التسجيل السابق يتوقف ويُفرغ قبل تحميل تسجيل المشهد الجديد.

## التشغيل كصفحة ويب

```bash
npm run sync:web
python3 -m http.server 4173 -d www
```

ثم افتح `http://localhost:4173`.

## تحويله إلى تطبيق عبر Capacitor

تمت إضافة منصتي Android وiOS. بعد كل تعديل على `index.html` أو `js` أو `style` أو `assets` شغّل:

```bash
npm run cap:sync
```

لفتح المشروع الأصلي:

```bash
npx cap open android
npx cap open ios
```

يتطلب بناء Android Android Studio وSDK، ويتطلب بناء iOS جهاز macOS وXcode. بيئة Linux الحالية أنشأت ملفات المنصتين ونسخت الأصول، لكنها لا تستطيع تشغيل Xcode أو توقيع IPA.

## الإعدادات

تتضمن اللعبة ثيم أحمر داكن، ثيم نوير، وثيم ورق التحقيق، مع خيار تعطيل الدم والظلال ووضع قراءة مدمج لتقليل طول الصفحة.
